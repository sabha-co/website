Sabha runs on one small server. The app, its SQLite database, its cache, background jobs and the WebSocket server all live together, so there's no separate database to set up or pay for. You own the server and every message on it.

- [Deploy Sabha](/self-hosting/deploy/): put it on a server with Kamal, configure it, update it and back it up.
- [Branding](/self-hosting/branding/): your workspace's name, logo and colors, its icons, and the address it sends email from.
- [Single sign-on](/self-hosting/sso/): sign people in through an app they already use.
