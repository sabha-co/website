Your members should see your workspace, not a generic chat app. Sabha's branding comes from a handful of environment variables and image files, plus a logo you can upload from the app.

## Environment variables

Set these in your `.env` file, then run `kamal deploy` to apply them. See [Deploy Sabha](/self-hosting/deploy/#configuration) for how configuration reaches the server.

### Name and address

```bash
# Your workspace's name: page titles, emails, sign-in pages, the installed app
APP_NAME="Northwind Studio"

# Short name under the icon on a phone's home screen (keep it under 12 characters)
APP_SHORT_NAME="Northwind"

# Description for the installed app and page metadata
APP_DESCRIPTION="Where the Northwind team talks"

# Your domain, without https://
APP_HOST="chat.northwind.studio"
```

### Contact and email sender

```bash
# Shown in error messages and help pages
SUPPORT_EMAIL="support@northwind.studio"

# The "From" on outgoing email: sign-in codes, notifications and so on
MAILER_FROM_NAME="Northwind Studio"
MAILER_FROM_EMAIL="noreply@northwind.studio"
```

### Installed app colors

These color the mobile browser's address bar and the splash screen of the [installed app](/features/push-notifications/). They don't change the colors inside Sabha.

```bash
# Address bar and app theme (default: #1d4ed8)
THEME_COLOR="#1d4ed8"

# Splash screen background (default: #ffffff)
BACKGROUND_COLOR="#ffffff"
```

Use your brand's main color for `THEME_COLOR`, and make sure it contrasts well with `BACKGROUND_COLOR`.

### Analytics

If you use [Umami](https://umami.is), set your website ID. Leave it unset to turn analytics off.

```bash
UMAMI_WEBSITE_ID="your-website-id"

# Only if you run your own Umami (default: cloud.umami.is)
# UMAMI_HOST="umami.northwind.studio"
```

### Embedding

To allow other sites to show Sabha in an iframe, list them here, separated by commas. By default only your own domain and its subdomains can.

```bash
CSP_FRAME_ANCESTORS="https://northwind.studio, https://*.northwind.studio"
```

## Logo

Administrators can upload a logo at the top of **Account settings**. It takes effect right away, without a deploy, and replaces the default app icon everywhere it appears: in the app, as the browser tab icon in browsers that don't use the SVG icon, as the iPhone home-screen icon and as the installed app's icon.

The uploaded logo doesn't change the SVG tab icon or the link-preview images. Replace those files, below, if you want them branded too.

## Icon and image files

To change the defaults themselves, replace these files in your copy of the repository and deploy. Other images in the repository aren't used for icons.

### Browser tab icon

| File | Purpose |
|------|---------|
| `public/icon.svg` | The tab icon in modern browsers |

### App icon

These cover browsers without SVG icon support, the iPhone home-screen icon and the installed app. Replace both. They're also what Sabha shows when no logo has been uploaded.

| File | Size | Purpose |
|------|------|---------|
| `app/assets/images/logos/app-icon.png` | 512×512 | PNG tab icon, iPhone home-screen icon, installed app icon |
| `app/assets/images/logos/app-icon-192.png` | 192×192 | Smaller installed app icon |

### Link previews

Shown when someone shares a link to your workspace in another app or on social media.

| File | Recommended size | Purpose |
|------|------|---------|
| `public/sabha-og.jpg` | 1200×630 | The preview card image |
| `public/icon.png` | 512×512 | The preview logo |

## Example

```bash
APP_NAME="Startup Founders Club"
APP_SHORT_NAME="SFC"
APP_DESCRIPTION="A place for early-stage founders"
APP_HOST="chat.startupfounder.club"
SUPPORT_EMAIL="help@startupfounder.club"
MAILER_FROM_NAME="Startup Founders Club"
MAILER_FROM_EMAIL="noreply@startupfounder.club"
THEME_COLOR="#10b981"
BACKGROUND_COLOR="#ffffff"
```

## Troubleshooting

### Changes don't appear

Environment variables are read when Sabha starts. Run `kamal deploy` after changing them.

### Icons don't update

Replaced files only take effect after a deploy, because the image is rebuilt with them. Then clear your browser cache or check in a private window. For the installed app, remove it and install it again.

### The email sender name doesn't change

1. Check that both `MAILER_FROM_NAME` and `MAILER_FROM_EMAIL` are set.
2. Deploy again so Sabha picks them up.
3. Make sure the sending domain is verified with your email provider. Some providers won't send from an unverified domain.
