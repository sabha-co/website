A self-hosted Sabha is one workspace, and the workspace brands it. Most of its branding is set in the app, with no deploy. The server supplies only its address, the address it sends email from, and a few image files.

## In the app

You name the workspace when you first set Sabha up. Administrators change its name, logo and accent color in **Settings → Identity**. See [Name, logo and email](/workspace/identity/).

| Setting | Where it shows |
|---|---|
| Name | Page titles, the sign-in and join pages, link previews, the installed app's name, email subjects and the email sender's name |
| Logo | The sidebar, the sign-in and join pages, the browser tab icon in browsers that don't use the SVG icon, the iPhone home-screen icon and the installed app's icon |
| Accent color | Links, selections and highlights everywhere, and the browser's theme color |

The logo can be JPEG, PNG, GIF or WebP. Without one, Sabha shows the name's first letter on the accent color. The logo doesn't change the SVG tab icon or the link-preview images; replace those [files](#icon-and-image-files) to brand them too.

### Signing in with single sign-on

If your first administrator arrives through [single sign-on](/self-hosting/sso/), there's no setup form to name the workspace. It takes its name from `BOOTSTRAP_WORKSPACE_NAME`, read once at that moment, or "Sabha" if that's unset. Rename it in Settings afterwards.

## Environment variables

Set these in your `.env` file, then run `kamal deploy`. See [Deploy Sabha](/self-hosting/deploy/#configuration).

### Address and email

```bash
# Your domain, without https://. Required: Sabha won't start without it.
APP_HOST="chat.northwind.studio"

# The address email is sent from. Your email provider must have verified it.
# Email shows the workspace's name as the sender.
MAILER_FROM_EMAIL="noreply@northwind.studio"
```

Without `MAILER_FROM_EMAIL`, Sabha sends from `noreply@` your `APP_HOST`.

### Analytics

If you use [Umami](https://umami.is), set your website ID. Leave it unset to turn analytics off.

```bash
UMAMI_WEBSITE_ID="your-website-id"

# Only if you run your own Umami (default: cloud.umami.is)
# UMAMI_HOST="umami.northwind.studio"
```

### Embedding

By default only your own domain and its subdomains can show Sabha in an iframe. To allow other sites, list every site that may, separated by commas:

```bash
CSP_FRAME_ANCESTORS="https://chat.northwind.studio, https://*.northwind.studio, https://intranet.northwind.studio"
```

The list replaces the default, so include your own domain if Sabha should still be able to frame itself.

## Icon and image files

To change the default icons and images, replace these files in your copy of the repository and deploy. Other images in the repository aren't used for icons.

### Browser tab icon

| File | Purpose |
|------|---------|
| `public/icon.svg` | The tab icon in modern browsers |

### App icon

These cover browsers without SVG icon support, the iPhone home-screen icon and the installed app, while no logo has been uploaded. Replace both.

| File | Size | Purpose |
|------|------|---------|
| `app/assets/images/logos/app-icon.png` | 512×512 | PNG tab icon, iPhone home-screen icon, installed app icon |
| `app/assets/images/logos/app-icon-192.png` | 192×192 | Smaller installed app icon |

### Link previews

Shown when someone shares a link to your workspace in another app or on social media.

| File | Recommended size | Purpose |
|------|------|---------|
| `public/sabha-og.jpg` | 1200×630 | The preview card image |
| `public/icon.png` | 512×512 | The preview logo |

## Troubleshooting

### Changes don't appear

Environment variables are read when Sabha starts. Run `kamal deploy` after changing them. Changes in Settings → Identity apply straight away.

### Icons don't update

Replaced files only take effect after a deploy, because the image is rebuilt with them. Then clear your browser cache or check in a private window. For the installed app, remove it and install it again.

### Email comes from the wrong name or address

The sender's name is the workspace's name: rename the workspace in Settings → Identity, with no deploy. The address is `MAILER_FROM_EMAIL`. Check it's set and that your email provider has verified it, then deploy. **Settings → About** can send you a test email.
